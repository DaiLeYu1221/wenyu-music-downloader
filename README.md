# 文宇音乐聚合搜索 & 下载器

一个基于 Python 的命令行音乐搜索与下载工具，支持多平台聚合搜索，自动下载最高音质并嵌入歌词、封面等元数据。

## 功能特性

- 多平台搜索：网易云音乐、QQ音乐、酷我音乐
- 最高音质优先：自动尝试最高音质，失败自动降级
- 元数据嵌入：下载时自动写入歌名、歌手、专辑、歌词、封面
- 多格式支持：MP3、FLAC、M4A 自动识别与适配
- 简洁交互：选择平台后直接搜索，选序号即下载

## 支持平台

| 平台 | 最高音质 | 歌词 |
|------|---------|------|
| 网易云音乐 | 标准 | 支持 |
| QQ音乐 | FLAC | 支持 |
| 酷我音乐 | Hi-Res (999k) | 支持 |

## 快速开始

### 环境要求

- Python 3.8+
- Windows / macOS / Linux

### 安装

```bash
git clone https://github.com/YOUR_USERNAME/wenyu-music-downloader.git
cd wenyu-music-downloader
pip install -r requirements.txt
```

### 配置

编辑 `config.json`，填入你的 API 密钥：

```json
{
    "api_key": "YOUR_API_KEY_HERE"
}
```

> API 密钥获取：<https://api.yaohud.cn>

### 运行

```bash
python main.py
```

## 项目结构

```
├── config.json           # API 密钥配置（需自行填写）
├── config.py             # 平台端点与音质策略配置
├── api_client.py         # 统一音乐平台 API 客户端
├── lyrics.py             # 歌词获取模块
├── tagger.py             # 元数据写入模块（MP3/FLAC/M4A）
├── downloader.py         # 下载器（音质降级 + 元数据嵌入）
├── main.py               # CLI 主程序入口
└── requirements.txt      # Python 依赖
```

## 音质降级策略

| 平台 | 降级顺序 |
|------|---------|
| QQ音乐 | FLAC → 320kbps → 128kbps |
| 酷我音乐 | Hi-Res → 无损 → 320kbps → 192kbps → 128kbps |

最高音质获取失败时自动递归尝试下一个等级。

## 元数据写入

| 格式 | 标题 | 歌手 | 专辑 | 歌词 | 封面 |
|------|------|------|------|------|------|
| MP3  | TIT2 | TPE1 | TALB | USLT | APIC |
| FLAC | title | artist | album | lyrics | Picture |
| M4A  | ©nam | ©ART | ©alb | ©lyr | covr |

所有文本使用 UTF-8 编码，确保中文正常显示。
